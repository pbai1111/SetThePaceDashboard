# Set the Pace Podcast — Dashboard

Internal dashboard for managing the **Set the Pace** podcast by New York Road Runners.

## Live Links

- [Main Dashboard](https://pbai1111.github.io/SetThePaceDashboard/sponsorship-dashboard.html) — Episode schedule, partner fulfillment tracker, and calendar planner
- [Peloton Partner View](https://pbai1111.github.io/SetThePaceDashboard/peloton-partner-view.html) — Episode schedule only (no sponsor data), shareable with Peloton

## What's Here

| File | Purpose |
|------|---------|
| `sponsorship-dashboard.html` | Main internal dashboard (episodes, sponsorships, calendar) |
| `peloton-partner-view.html` | Clean partner-facing episode view for Peloton |

Both are single-file HTML pages with embedded CSS and JavaScript — no build step required.

## How to Update

1. Make changes in the **Excel master** (`SET THE PACE PODCAST - PROJECT MANAGEMENT MASTER.xlsx`)
2. Update the HTML file(s) to match
3. Push to `main` — GitHub Pages deploys automatically
